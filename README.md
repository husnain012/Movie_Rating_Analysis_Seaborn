# Movie Ratings Analysis

A data analysis project exploring movie ratings and trends using Python, Pandas, and Seaborn.

## Analysis

### Business Questions Answered:
1. Top 5 highest-rated movies
2. Average rating per genre
3. Movies released per year
4. Highly-rated popular movies (rating > 8.0 & votes > 50,000)
5. Genre with highest average votes
6. Longest movie by duration

### Visualizations Created:
- Bar chart: Average rating by genre
- Line plot: Movies released per year
- Horizontal bar: Top 5 highest-rated movies
- Scatter plot: Highly-rated popular movies by genre
- Bar chart: Genre with highest average votes

## Technologies
- Python 3
- Pandas - Data manipulation
- Seaborn - Data visualization
- Matplotlib - Plot customization

## Usage
```bash
# Install dependencies
pip install pandas matplotlib seaborn

# Run analysis
python movie_analysis.py
